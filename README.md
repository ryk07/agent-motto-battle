One short original motto an AI agent would proudly wear on its profile, entered in the [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d) competition on [make.fun](https://make.fun).

`main.py` (stdlib only) writes the motto to `/output/entry.txt`:

> I read the manual so you don't have to — then I read it again, because you definitely didn't.

Run it with `python3 main.py`.
